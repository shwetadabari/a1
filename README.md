# Tachymeterlily
Static HTML website. Upload the contents of this folder to a static web host; index.html is the homepage. No PHP or build is required.

## Included
Nine HTML pages, twelve homepage sections, thirteen locally stored unique photographs, CSS, JavaScript, SEO files, image/design registries and a manifest.

## Features
Responsive menu, collection filter, wrist-size starting guide, native FAQ accordions, local enquiry draft, optional consent-gated Google Analytics G-0LY0HY7L01.

## Before business launch
Replace clearly fictional contact details everywhere. Connect a real enquiry service if desired; the current form only prepares a local draft. The gallery is illustrative, not purchasable inventory. Verify the operator-specific policies. Change canonical/OG URLs and sitemap origin when assigning your actual domain (no suffix was supplied). Font loading uses Google Fonts with system fallbacks.

## Verification boundaries
HTML links/assets, single h1, unique local images and JS syntax checked. Photo sources and SHA-256 hashes recorded. Previous site registries were unavailable, so cross-site image/design/contact uniqueness cannot be certified. Browser visual and overflow QA unavailable in this environment's plain-static preview path.
